# Scrimmage_Code

Two-driver TeleOp for the 2026-27 REV DUO FTC Starter Bot.

Drop `revbot.java` into `TeamCode/src/main/java/org/firstinspires/ftc/teamcode/` of your FTC SDK project.

## Hardware config names

| Port | Name |
|---|---|
| Motor 0 | leftDrive |
| Motor 1 | rightDrive |
| Motor 2 | intakeMotor |
| Motor 3 | flywheel |
| Servo 0 (continuous) | crServo |
| Servo 1 | pollenServo |

## Controls

| Gamepad | Control | Function |
|---|---|---|
| 1 | Left stick Y | Drive forward and back |
| 1 | Right stick X | Turn |
| 1 | Right trigger | Intake in |
| 1 | Left trigger | Intake out |
| 2 | A | Flywheel on (0.7) |
| 2 | Y | Flywheel off |
| 2 | X | Pollen pusher to 0.5 |
| 2 | B | Pollen pusher to 0 |
| 2 | Dpad up / down | Feeder forward / reverse |

Register gamepads on the Driver Hub with Start + A (User 1) and Start + B (User 2).
